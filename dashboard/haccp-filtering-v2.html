중요관리점(CCP-2) 모니터링일지 [여과 공정] (New Version)

여과망 상태와 여과 압력을 확인하고 기록합니다.

한계기준

  • 여과망: 120mesh
  • Cartridge Filter: 100μm
  • 최대 여과 압력: 0.3MPa (약 43.5psi)

점검 주기

  • 여과망·Cartridge Filter 설치 시 규격 확인
  • 작업 시작 전 및 작업 종료 후 확인
  • 압력 0.3MPa 이상 시 확인

점검 방법

  • 여과망 파손 여부 확인
  • 설정된 여과 압력 기준 확인
  • 파손 발견 시 정상 여과망으로 즉시 교체
psi
입력 대기

개선조치 안내

  • 여과망 파손 발견 시 정상 여과망으로 즉시 교체합니다.
  • 이탈 여과망은 폐기 또는 재사용 금지 처리합니다.
  • 정상 여과망을 사용해 여과 공정을 다시 진행합니다.
