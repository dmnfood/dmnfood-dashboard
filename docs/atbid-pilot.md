# aT 자동 조회 파일럿

참깨 입찰 분석의 수동 HAR 업로드와 별도로 기간 선택 후 자동 조회를 실행한다.
로그인 정보, 브라우저 쿠키, 확장 프로그램은 사용하지 않는다.

## 확인한 공개 조회 규칙 (2026-09-29)

- 화면: https://www.atbid.co.kr/aTBidP/index.html?menuid=aTBidP_001001003
- 공개 화면 코드: https://www.atbid.co.kr/aTBidP/AT/BID/STS/BIDSTS002M00.xfdl.js
- 품목 조회: `POST https://www.atbid.co.kr/u16/BUAG02L1/getItem.do` — 참깨 코드 `11`.
- 결과 조회: `POST https://www.atbid.co.kr/u16/BUAG02L1/list.do`.
- Nexacro XML의 `dsSearch`에 `sSDate`, `sEDate`(YYYYMMDD), `sItemCd=11`,
  `sCancelYn=''`(낙찰취소 포함), `iCurPageNo`(1부터), `iPageSize=20`을 전달한다.
- 응답 `iTotalCnt`는 전체 건수, `dsBid`는 해당 페이지 결과다.
- 사이트는 표의 마지막 행을 넘겨 스크롤할 때 다음 페이지를 요청한다.
  파일럿은 같은 요청을 순차 실행하여 스크롤과 HAR 추출을 생략한다.

## 동작과 제한

- `/api/atbid`는 고정된 공개 조회 주소만 호출한다. 날짜와 페이지를 검증하며
  참깨 이외의 품목이나 임의 URL을 받지 않는다.
- 한 번에 최대 366일, 500페이지(10,000건), 서버 요청당 8초,
  브라우저 수집 전체 3분으로 제한한다.
- 페이지 건수, 전체 건수 변화, `RNUM` 순서, 입찰 ID 중복을 검사한다.
- 모든 페이지 수집이 성공한 후 기존 분석 함수에 전달한다.
  실패·중지·빈 결과 시 기존 분석을 유지한다. 수동 파일 선택은 진행 중 수집을 취소한다.
- aT의 공개 화면 내부 요청을 이용하며 보장된 외부 연동 API는 아니다.
  응답 변경이나 배포 서버 연결 제한이 생기면 수동 HAR 업로드를 사용한다.
- 기존 분석 계산은 유지한다. 제목 분류는 HAR와 자동 조회가 동일한 함수를 사용하며,
  참깨 바로 뒤의 상품 규격 괄호에서 원산지·등급·포장을 추출한다.
  앞쪽 지사명과 구분 괄호는 무시하고, 알려진 국가명의 `산` 접미사 유무는 통일한다.
